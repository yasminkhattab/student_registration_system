# Reference material

This directory contains the official course material used as the primary
requirements source.

## Files

| File | Purpose |
| --- | --- |
| `CS113_Project_Instructions.pdf` | Official brief: CLO marks, requirements, report/ZIP submission rules, rubric, deadline |

The PDF is committed with the project so every teammate and the marker works from the
same requirements. A text extract was used to reconcile
[`../docs/REQUIREMENTS.md`](../docs/REQUIREMENTS.md).

## Key facts

- Course: Programming II (CS113), Taibah University, First Semester 2026/2027.
- 15 marks: CLO 2.1 = 5, CLO 2.2 = 3, CLO 2.3 = 2, CLO 3.1 = 5.
- Groups of 4–5 students.
- Submission: report PDF (cover page + Sections 1–4) and source ZIP named
  `CS113_Section_Project_GroupX`.
- Deadline: **12 December 2026, 11:59 PM** via Blackboard.
- Presentation is pre-recorded; each member presents their assigned part.

Do not add solutions, previous years' reports or copyrighted material from other
groups to this directory.
